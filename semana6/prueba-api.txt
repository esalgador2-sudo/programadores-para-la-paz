=== RESPUESTA DEL SERVIDOR ===

Cuando se envía una petición HTTP de tipo POST a la URL http://localhost:3000/registro con el cuerpo en formato JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor procesa la información y devuelve una respuesta con un código de estado 200 OK y el siguiente objeto JSON:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

==============================
EXPLICACIÓN DEL PROCESO:

1. Recepción: El servidor Express intercepta la petición POST en la ruta '/registro'.
2. Lectura: Gracias al middleware 'express.json()', el servidor extrae las propiedades 'nombre' y 'mensaje' desde el cuerpo (req.body) de la solicitud entrante.
3. Respuesta: El método 'res.json()' empaqueta las variables capturadas junto con el string de confirmación ("Datos recibidos") y se las envía de vuelta al cliente en formato estructurado.
